# Mokepon

## Iniciar el juego

1. Instala las dependencias con `npm install`.
2. Inicia el servidor con `npm start`.
3. Abre `http://localhost:8080` en el navegador.

Para jugar desde otro dispositivo de la misma red, abre en él la dirección IP local
del equipo que ejecuta el servidor, usando el puerto `8080`. El juego usa el mismo
origen desde el que se carga la página, así que no es necesario cambiar una IP en
el código.
